title=Server Event Manager [BETA]
description=[h1]Server Event Manager [BETA][/h1]
description=An in-game admin console for [b]Project Zomboid Build 42 multiplayer servers[/b]. Server admins set up, trigger, schedule and cancel server events (airdrops, aircraft crashes, hostile camps, migrating hordes, wildfires, super zombies, convoy wrecks, base sieges, manhunts and rescue calls) with every option in the game UI. Players get on-screen alerts, sounds and map markers. NPC events use Project A-Life.
description=
description=[b]This mod is in beta and under active development. Expect bugs.[/b] If something breaks, [url=https://github.com/JoshuaSHenderson/ProjectZomboid-Server-Event-Manager/issues]report it on GitHub[/url] or comment here, with what you did and your console.txt.
description=
description=[h2]New in 0.4.0-beta[/h2]
description=Built from the 2026-11-03 live-server bug list and four play tests on the test server.
description=[list]
description=[*][b]Works out of the box.[/b] A new server starts with six safe events scheduled; Reset to Default brings them back.
description=[*][b]Clean Up At End.[/b] Any event can remove its crates, loot, zombies, vehicles and NPCs when it ends.
description=[*][b]Aircraft Crash.[/b] Picks from a list of known clear sites so planes land reliably, and the marker never moves.
description=[*][b]Under Siege[/b] waves come from several sides.
description=[*][b]Logs[/b] have timestamps and no cap.
description=[*][b]Options.[/b] Mark Hostiles, marker colours by event kind, Flyover Volume, and Set all plus 30 percent chance in loot tables.
description=[*][b]Fixes.[/b] Stuck events now end, guards no longer spawn inside wrecks, A-Life reputation is no longer lost on raiders, and marks show in first person with Stance Dots Viewpoint.
description=[/list]
description=
description=[h2]0.3.2-beta[/h2]
description=[b]Events survive log outs and restarts.[/b] An event carries on unchanged when its players log out, the server pauses or it restarts. Its zombies are kept by their persistent id and only count as gone when killed, so a horde no longer ends when you log out next to it. Leaving an event's area only pauses it; Leave Minutes is removed. Map circles come back after you log in again.
description=
description=[h2]0.3.1-beta[/h2]
description=[b]Export Logs.[/b] Save the event history and notices to a text file in your Zomboid/Lua folder, and copy them to the clipboard.
description=
description=[h2]0.3.0-beta[/h2]
description=Built from the second live-server list, tested with A-Life and Jeem.
description=[list]
description=[*][b]Aircraft Crash.[/b] A burning helicopter or plane wreck on open ground. A loud explosion everyone hears, fires that burn out, loot round it and optional guards.
description=[*][b]Hold your base.[/b] Under Siege marks the base on the map and gives you Return Minutes to get home. Miss it and enemies take over: some loot is gone, fires burn.
description=[*][b]Weapon Packs.[/b] Pick guns and melee weapons hostile NPCs carry, modded ones included.
description=[*][b]Loot where it belongs.[/b] Convoy loot is in its trunks and gloveboxes; a crash scatters its loot.
description=[*][b]Scales with players.[/b] Extra Per Player (Percent) grows an event per online player. Random guards have their own range.
description=[*][b]Harder NPCs.[/b] NPC Difficulty, Easy to Brutal.
description=[*][b]Radios matter.[/b] Exact With Radio shows the exact spot to players with a charged radio.
description=[*][b]Your time zone.[/b] Your local time beside the server's clock.
description=[*][b]For modders.[/b] Add events with SEM.registerEvent; they get presets, scheduling and logs. See MODDING.md.
description=[*][b]Quiet events.[/b] Show Notifications can be turned off.
description=[*][b]Test a schedule.[/b] Once, After Game Hours fires once, one game hour from now.
description=[*][b]Easier start.[/b] A Home page with update notes and a walkthrough. Copy presets. Import / Export no longer sticks.
description=[/list]

description=[h2]Optional dependencies[/h2]
description=This mod runs on its own, but everything with NPCs needs these:
description=[list]
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3803984183]Project A-Life[/url] - required for all NPCs: NPC guards, Hostile Camp survivors, Under Siege NPC waves, Stranger Calls For Help and Hunted.
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3806944055]Project A-Life - Jeem Extension[/url] - adds Jeem bases as targets and protected zones, and faction standing for the stranger's reward.
description=[/list]
description=Without A-Life, guards and camps use zombies, Under Siege runs zombie waves (Wave Type Zombies or Random), and Stranger Calls For Help and Hunted fail.

description=[h2]Events[/h2]
description=[list]
description=[*][b]Airdrop[/b] - crates with loot, smoke and a helicopter flyover, optionally guarded.
description=[*][b]Hostile Camp[/b] - a camp of hostile survivors with a loot crate as the prize. Raider zombies if A-Life is missing.
description=[*][b]Migrating Horde[/b] - a horde that spawns out of sight and walks to a player, a town, the countryside or a spot.
description=[*][b]Wildfire[/b] - fires that spread, held to a size you set, then put out. Safehouses and Jeem bases never burn.
description=[*][b]Super Zombies[/b] - tougher, faster zombies with green skin, and an optional red boss.
description=[*][b]Convoy Wreck[/b] - damaged vehicles on a road, their cargo in the trunks and gloveboxes.
description=[*][b]Under Siege[/b] - waves of NPCs or zombies attack a safehouse or Jeem base; get back in time or lose it. NPC waves need A-Life.
description=[*][b]Stranger Calls For Help[/b] - reach a friendly NPC in time and beat the wave for a faction bonus. Needs A-Life.
description=[*][b]Hunted[/b] - NPCs track one player until they or the player die. Needs A-Life.
description=[*][b]Aircraft Crash[/b] - a burning helicopter or plane wreck on open ground, with an explosion, loot scattered on the ground and optional guards. The fire goes out; the wreck stays.
description=[/list]
description=
description=[h2]The console[/h2]
description=[list]
description=[*]Open with F7, the right-click menu or the Admin Panel. Admins only; the server checks every command.
description=[*]Every option has a hover blurb. Save named presets per event.
description=[*]Table pickers for items, vehicles, outfits, players and bases, modded ones included.
description=[*]Loot Packs, Vehicle Packs and Weapon Packs, with defaults ready to go. Loot packs have a tier, and an event can pick Random Low, Medium or High Tier.
description=[*]Active Events lists every live run with Cancel and Teleport. Logs show what fired and why; Export saves them to a file.
description=[*]Limits cap zombies per event and events at once.
description=[*]Import / Export the whole config as JSON.
description=[*]Resizable windows, including the Server Events bar.
description=[/list]
description=
description=[h2]For players[/h2]
description=[list]
description=[*]A warning, then a start notification, each with the admin's own message. Optionally only for players carrying a charged radio, or turned off.
description=[*]Markers on the world map and minimap; hover one to see what it is.
description=[*]A Server Events bar showing what is incoming, active and recently over. It folds away.
description=[*]Red and green arrows over what an event spawned, and direction arrows to the last few targets.
description=[/list]
description=
description=[h2]Scheduler[/h2]
description=A table of schedules, each running one event, optionally with a preset:
description=[list]
description=[*][b]Random Game Time[/b] - every few game days at random, with quiet hours.
description=[*][b]Scheduled Game Time[/b] - every N game days at a set hour.
description=[*][b]Real-World Window[/b] - days and times on the server clock, skipped if its conditions are not met.
description=[*][b]Once, After Game Hours[/b] - fires one time after 1 to 72 game hours, then turns itself off.
description=[*][b]Generate Random[/b] - adds random entries, asking how many.
description=[/list]
