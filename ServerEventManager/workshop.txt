Expect bugs.[/b] If something breaks, please tell us: [url=https://github.com/JoshuaSHenderson/ProjectZomboid-Server-Event-Manager/issues]report it on GitHub[/url] or leave a comment here, with what you did and your console.txt if you can.

description=[h2]New in 0.2.0-beta: the live-server update[/h2]
description=Beta testing on a live server turned up a long list. This update works through it:
description=[list]
description=[*][b]A new console.[/b] One page per event: pick a preset, edit it, Update, Save As or Trigger Now. A sectioned menu, resizable windows, and vanilla hover help on every setting.
description=[*][b]Under Siege, wave by wave.[/b] "They are coming!", they hit the base, you heal up, they come back. Everyone's bar shows the wave and the countdown.
description=[*][b]Nothing is lost to a full server.[/b] Scheduled events wait as Pending for the next slot. Force an event any time; it never counts against the limit.
description=[*][b]Import and export.[/b] Your whole config as JSON, validated before it is saved. Copy a setup from one server to another.
description=[*][b]Several packs per event.[/b] List as many loot or vehicle packs as you like, and each crate picks one.
description=[*][b]Forests actually avoided.[/b] Events count the real trees where they land and move to clear ground.
description=[*][b]Hordes finish.[/b] Stand on the spawn point and the rest come in from somewhere else.
description=[*][b]Only online bases.[/b] An event never targets a base with nobody online.
description=[*][b]For admins and players.[/b] Exact grey dots on the admin map, time left and status on the player bar, a radio crackle with every message, and a minimum character age for random targets.
description=[/list]
description=
description=[h2]Optional dependencies[/h2]
description=This mod runs on its own, but everything with NPCs needs these:
description=[list]
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3803984183]Project A-Life[/url] - required for all NPCs: NPC guards, Hostile Camp survivors, Under Siege, Stranger Calls For Help and Hunted.
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3806944055]Project A-Life - Jeem Extension[/url] - adds Jeem bases as targets and protected zones, and faction standing for the stranger's reward.
description=[/list]
description=Without A-Life, guards and camps use zombies, and those three events refuse to start.
description=
description=An in-game admin console for Build 42 multiplayer servers. Set up, force, schedule and cancel server events, with every option in the UI.

description=[h2]Events[/h2]
description=[list]
description=[*][b]Airdrop[/b] - crates with loot, smoke and a helicopter flyover, optionally guarded.
description=[*][b]Hostile Camp[/b] - a camp of hostile survivors with a loot crate as the prize. Raider zombies if A-Life is missing.
description=[*][b]Migrating Horde[/b] - a horde that spawns out of sight and walks to a player, base or spot.
description=[*][b]Wildfire[/b] - fires that spread, held to a size you set, then put out. Safehouses and Jeem bases never burn.
description=[*][b]Super Zombies[/b] - tougher, faster zombies with green skin, and an optional red boss.
description=[*][b]Convoy Wreck[/b] - damaged vehicles on a road with a loot crate.
description=[*][b]Under Siege[/b] - waves of NPCs attack a safehouse or Jeem base. Needs A-Life.
description=[*][b]Stranger Calls For Help[/b] - reach a friendly NPC in time and beat the wave for a faction bonus. Needs A-Life.
description=[*][b]Hunted[/b] - NPCs track one player until they or the player die. Needs A-Life.
description=[/list]
description=
description=[h2]The console[/h2]
description=[list]
description=[*]Open with F7, the right-click menu or the Admin Panel. Admins only; the server checks every command.
description=[*]Every option has a hover blurb. Save named presets per event.
description=[*]Table pickers for items, vehicles, outfits, players and bases, modded ones included.
description=[*]Loot Packs and Vehicle Packs, with defaults ready to go. Packs have a tier, and an event can pick Random Low, Medium or High Tier.
description=[*]Active Events lists every live run with Cancel and Teleport. Logs show what fired and why.
description=[*]Limits cap zombies per event and events at once.
description=[*]Import / Export the whole config as JSON.
description=[*]Several loot or vehicle packs per event.
description=[*]Resizable windows, including the Server Events bar.
description=[/list]
description=
description=[h2]For players[/h2]
description=[list]
description=[*]A warning, then a start notification, each with the admin's own message. Optionally only for players carrying a charged radio.
description=[*]Markers on the world map and minimap; hover one to see what it is.
description=[*]A Server Events bar showing what is incoming, active and recently over. It folds away.
description=[*]Red and green arrows over what an event spawned, and direction arrows to the last few targets.
description=[/list]
description=
description=[h2]Scheduler[/h2]
description=A table of schedules, each running one event, optionally with a preset:
description=[list]
description=[*][b]Random Game Time[/b] - every few game days at random, with quiet hours.
description=[*][b]Scheduled Game Time[/b] - every N game days at a set hour.
description=[*][b]Real-World Window[/b] - days and times on the server clock, skipped if its conditions are not met.
description=[*][b]Generate Random[/b] - adds random entries, asking how many.
description=[/list]

description=[h2]Notes[/h2]
description=[list]
description=[*]Build 42.21 or newer. Multiplayer servers only; the console is hidden in singleplayer.
description=[*]Wildfire protects safehouses, Jeem bases and A-Life homes. It cannot see an unclaimed base.
description=[*]NPCs spawned by A-Life stay in the world when an event ends.
description=[/list]
